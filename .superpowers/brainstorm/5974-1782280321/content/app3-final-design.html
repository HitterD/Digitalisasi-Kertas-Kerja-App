App3 Guided Upload — Final Design Summary

Spec akan ditulis dari desain ini jika sudah oke.

1. Scope

Route `/app3` tetap gabung dua tab: Consolidation dan Evaluation. Redesign utama untuk Consolidation. Evaluation diselaraskan ringan agar topbar/tab/spacing tidak terasa beda.

NO NEW DEPTOKEN CSSDARK MODE

2. Topbar

Back button disamakan dengan App1/App2: transparent icon button, divider tipis, icon module 26px, title 13px, tab pill, theme toggle kanan.

  • Hapus hover inline manual.
  • Gunakan class CSS reusable untuk App3 header.
  • Tab aktif jelas dengan charcoal pill.

3. Guided Upload

Upload jadi fokus utama. Setiap slot punya status wajib/opsional/source/valid, filename jelas, dan aturan lanjut tampil eksplisit.

  • Master Lama = opsional.
  • EXA / ADD / INV = minimal satu source wajib.
  • CTA ekstrak filter disabled sampai valid.

4. Filter + Generate

Filter kategori memakai kartu count agar mudah scan dan tidak salah pilih. Generate hanya muncul sebagai satu primary CTA.

  • Summary: Total BAT, Selected, Effective records.
  • Kategori: ICT, ENG, BAT, HRGA, Kosong.
  • Processing / success / error jelas.

5. Layout Akhir

Topbar Unified
Back + module title + tab Consolidation/Evaluation + theme toggle.
Step 1 Upload
Empat slot file, aturan anti-salah upload, CTA ekstrak.
Step 2 Filter
Kartu kategori + count + selected state.
Step 3 Generate
Download Excel + feedback proses.
Evaluation
Diselaraskan ringan, bukan redesign penuh.

Non-goals

Tidak ubah API, tidak ubah algoritma konsolidasi, tidak tambah library, tidak redesign penuh App4 Evaluation, tidak tambah wizard route baru. Lazy path: styling + copy + struktur JSX minimal agar dampak besar tanpa rewrite.
