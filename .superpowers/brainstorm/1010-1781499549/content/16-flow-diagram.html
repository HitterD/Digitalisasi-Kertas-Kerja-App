Navigation Flow — Kertas Kerja Digital

Peta lengkap semua halaman dan bagaimana mereka terhubung. Garis solid = navigasi langsung. Garis dashed oranye = data flow antar modul. Klik kartu untuk lihat mockup.

Cara baca diagram

  • Garis solid charcoal: navigasi langsung user (klik tombol, klik link).
  • Garis dashed charcoal: navigasi sekunder / save-load (balik ke upload dengan session).
  • Garis dashed oranye (terracotta): data flow antar modul. Bukan klik user, tapi data yang dipakai bersama. Mis. hasil scan di App1 dipakai oleh App2 Extract untuk rekap.
  • Border dashed pada kartu: akses terbatas (admin only / Capacitor only / step lanjutan).

Alur lengkap

  1. Login → masuk dengan username + password (offline cache didukung).
  2. Bento Menu → 4 modul utama + 1 admin (admin only).
  3. App1 — Upload: pilih file dari lokal atau server. Lalu klik "Mulai Baru" → masuk Opname.
  4. App1 — Opname: kerja utama. Scan barcode per ruang, input kondisi, tanda tangan. Save/Load untuk restore sesi.
  5. App2 — Extract: tarik data hasil opname dari server, filter per departemen/lokasi, export Excel recouncil per ruang + MAT report.
  6. App3 — Master (Tab 1): upload 4 file (Master, EXA, ADD, INV) → pilih filter BAT/ENG/HRGA/ICT/kosong → generate Excel konsolidasi.
  7. App3 — Recouncil (Tab 2): upload hasil opname + master + ASPx → sistem compare → tabel match/missing/extra.
  8. Admin: kelola user, lihat audit trail, backup, system info. Hanya untuk role admin.

Mobile flow (Capacitor APK)

Pada mode tablet (Capacitor), Login → Bento Menu → langsung redirect ke App1 Upload. App2, App3, Admin disembunyikan (hanya web). User tidak bisa logout dari tablet kecuali tap tombol logout di header.
