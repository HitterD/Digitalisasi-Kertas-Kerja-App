Apa yang di-improve dari v2 → v3

  1. Layout 2-kolom (sidebar + main): meta, status, room nav dipindah ke sidebar kiri. Area kerja utama jadi full-width, tabel lebih lega dan mudah di-scan.
  2. Progress ring mini (48px): ganti progress bar panjang di header. Lebih ringkas, langsung terlihat di sidebar, tidak makan ruang horizontal.
  3. Header sticky super slim (12px padding): turun 2px dari v2. Lebih banyak ruang vertikal untuk tabel.
  4. Action bar dirampingkan: hanya 4 tombol (Ruang Custom, Save/Load, Export PDF, Sync Server). Tidak ada room-nav di header — pindah ke sidebar.
  5. Search dipromosikan: lebar 380px, prominent, dengan padding lebih besar (11px 14px). Fungsi utama opname adalah scan barcode — harus paling gampang dijangkau.
  6. Input di tabel transparan sampai hover row: saat tidak di-hover, input "tak terlihat" — barcode/nama jadi fokus. Saat hover row, input muncul dengan background cream + border halus. Klik/focus: oranye ring.
  7. Kolom PRL disingkat (03/23 bukan 03/2023) untuk hemat ruang, tahun 2-digit cukup untuk konteks internal.
  8. Footer tabel info digabung: "0 dari 18 dicatat · 0 belum ada barcode" satu baris, tidak duplikat.
  9. Sidebar collapsible-ready: di mobile, sidebar bisa jadi drawer. Di desktop, sticky 280px. Dot grid 8-kolom pas untuk lebar 280px.

Kenapa lebih efisien

  • Hierarki visual jelas: mata langsung tahu "ini ruangan apa" (sidebar kiri) → "ini daftar kerjanya" (main). Tidak ada info konteks yang harus dicari.
  • 1 fokus, 1 area: scroll utama cuma di tabel. Sidebar tetap, tidak hilang saat scroll.
  • Default state bersih: input di tabel transparan = "tidak ada gangguan". Hanya muncul saat relevan (hover/focus).
  • Action bar di atas tabel: tombol-tombolnya dekat dengan outputnya, bukan di header yang terpisah.

Hover ke baris tabel (input akan muncul), hover ke dot room (tooltip), dan click button mana saja. Balas di terminal.
