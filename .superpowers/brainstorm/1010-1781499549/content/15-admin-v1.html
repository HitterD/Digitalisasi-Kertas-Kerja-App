Struktur

  1. In-app header (sama): KKD + "System Configuration" + role badge terracotta di kanan + BARCODE CHECKER
  2. Page header: meta uppercase + display title + admin badge "ADMINISTRATOR · andi.sja"
  3. Tabs (4): Users · Audit Trail · Backup · System Info. Aktif = charcoal text + 2px terracotta underline.
  4. Tambah User form (inline di atas tabel): Username + Password + Role + tombol Tambah terracotta. Tidak pakai modal — langsung inline, lebih cepat.
  5. Users table: Avatar monogram + Username + Last login + Role pill (admin terracotta / user abu-abu) + 3 toggle untuk akses App1/App2/App3 + Status (Aktif/Offline) + Aksi (Reset PW / Hapus)

Animasi

  • Tab hover: bg charcoal 4% transparan, active: charcoal text + 2px terracotta bottom border
  • Toggle switch: knob slide 200ms cubic-bezier, bg charcoal ke hijau saat on
  • Row hover: cream pucat
  • Tombol Reset PW: ghost, hover border charcoal
  • Tombol Hapus: ghost merah, hover bg merah pucat + border merah + text merah
  • Avatar admin: charcoal bg + terracotta text (visual hierarchy: admin "terlihat")
  • Role pill admin: bg terracotta 10% + text terracotta (eye-catching)
