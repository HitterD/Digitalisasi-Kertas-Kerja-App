Flow user-friendly (3 step eksplisit)

  1. Step 1 — Pipeline Ingestion: upload 4 file (Master, EXA, ADD, INV). Sudah selesai = card collapse jadi ringkasan, klik untuk expand.
  2. Step 2 — Pilih Filter (AKTIF): 5 kategori (ICT, ENG, BAT, HRGA, Kosong) muncul sebagai card dengan count per kategori. Multi-select. Live summary di bawah: "Filter Terpilih: ICT, ENG — Total 390 record".
  3. Step 3 — Generate Excel: disabled sampai Step 2 diproses. Setelah Excel ter-generate, card jadi hijau dengan tombol unduh + statistik.

Kenapa lebih user-friendly

  • Stepper visual di header: user selalu tahu "saya di mana". Tidak ada hidden step.
  • Count per filter SEBELUM klik — user bisa putuskan "saya mau ICT + ENG (390)" tanpa harus pilih buta. Sebelumnya: klik tombol "Ekstrak", baru tahu ada filter apa.
  • Live summary di bawah filter: "Total 390 record" update real-time saat user centang/uncentang.
  • "Pilih Semua" / "Reset": tidak perlu klik 5 kali kalau mau semua atau tidak ada.
  • Step 1 collapsible setelah selesai: tidak hilang dari pandangan, tapi tidak makan ruang.
  • Disabled state jelas di Step 3 — tidak bisa diproses sebelum waktunya.
  • Tombol "Kembali" di Step 2: kalau salah upload, user bisa balik ke Step 1 tanpa reset semua.

Animasi

  • Stepper line hijau mengalir saat step selesai (400ms)
  • Filter card hover: border gelap, lift -1px
  • Filter selected: bg charcoal + shadow + count pill terracotta (200ms)
  • Live summary: angka "390" update halus saat toggle filter
  • Tombol "Generate Excel" terracotta: lift -1px + shadow oranye hover, scale 0.97 click
