Jawaban: upload file di sisi mana?

Di desain baru App3 (Tahap 1 — Consolidation), upload file ada di card "Pipeline Ingestion" di atas halaman, di bawah page header. Setelah klik "Ekstrak Filter Kategori", card ini collapse (sticky minimized) dan tabel Consolidation muncul di bawahnya.

Struktur upload card

  1. Card header (1 baris): nomor step 01 + "Pipeline Ingestion" + sub-descripsi + status count (3 dimuat, 1 opsional) + dot hijau
  2. Upload zones (3 kolom: Master Eksisting, Sumber EXA, Sumber ADD) — 1.5px dashed border, icon-wrap dengan transition, hover = border terracotta + lift -3px
  3. Sumber INV (full-width baris ke-2) — zona horizontal lebih lebar untuk file besar, dengan status pill "BELUM DIMUAT"
  4. Loaded state: border hijau 50%, bg hijau pucat 4%, icon stroke hijau

Animasi

  • Zone hover: border terracotta, bg cream, lift -3px, soft shadow oranye pucat, icon scale 1.1
  • Loaded zone: pulse halus pada dot hijau (seperti RECENT dot di bento)
  • Tombol "Ekstrak Filter Kategori" terracotta: lift -1px + shadow oranye 6px saat hover, scale 0.97 saat click
  • Setelah proses: card ini collapse jadi strip kecil sticky di atas, tabel muncul dengan fade-in 250ms

Hover ke upload zone yang sudah dimuat (hijau) dan yang belum (abu-abu). Balas di terminal.
