Apa yang beda dari brutalism

  • Tombol "LANJUTKAN" & "AMBIL DARI SERVER": dari 4px 4px 0 charcoal hard-shadow → pill charcoal + terracotta. Hover: lift + soft shadow. Click: scale 0.98.
  • Page title: dari `KERTAS KERJA OPNAME` uppercase mono → mixed case Sora 24px + meta uppercase mono di atasnya.
  • 3-card layout: dari 2+1 bento grid → tetap 3 kolom (Session | Network | Database) tapi dengan soft card, hairline border, shadow 1px+6px.
  • Upload zone: dari 2px solid border indigo dengan floating icon animasi → 1.5px dashed charcoal 12%, icon-wrap dalam container, hover border terracotta + icon bg terracotta pucat.
  • Empty state: dari icon besar + text generic → italic di dalam dashed box kecil (lebih tenang, tidak lebay).

Flow dari Upload → Opname

  1. User pilih salah satu: Lanjutkan dari Lokal (muka Save/Load modal) ATAU Ambil dari Server (muka Server File Browser modal).
  2. Setelah file dimuat, parsedData state terisi, halaman re-render ke view "File Berhasil Dibaca" dengan daftar sheet + tombol "Mulai Baru" / "Tambah Ruangan" / "Pisahkan File".
  3. Setelah klik "Mulai Baru", navigasi ke /app1/opname dengan state baru. Halaman Opname (v4) ambil alih.

Hover ke card, button, dan upload zone. Balas di terminal.
