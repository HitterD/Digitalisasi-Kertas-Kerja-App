Cara pindah ruangan (3 cara)

  1. Tombol ‹ › di sebelah dropdown — paling cepat, juga bisa pakai tombol panah keyboard.
  2. Dropdown pilih langsung dari daftar 79 ruangan (muncul dengan progress masing-masing: "1. Ruang 801 (5/18)").
  3. Klik dot di grid navigasi 1-79 — hover dot muncul tooltip nama ruang, klik langsung lompat. Dot aktif: ring oranye 2px. Selesai: charcoal. Proses: oranye solid. Belum: hollow.

Animasi dipasang

  • Card & button: hover lift 2px, border darken, shadow membesar; click scale 0.98
  • Row tabel: hover cream pucat, row checked dapat strip oranye 3px di kiri
  • Checkbox: border jadi oranye saat hover, centang muncul 200ms saat on
  • Toggle pill ADA/TDK: slide oranye ke pilihan
  • Dot room: scale 1.4 + tooltip muncul saat hover
  • Arrow prev/next: border + icon jadi oranye saat hover, scale 0.92 saat click
  • Sync Server button: bg naik ke #D87554 + shadow oranye saat hover

Arahkan mouse ke dot, button, row, dan input untuk lihat semua animasi. Balas di terminal.
