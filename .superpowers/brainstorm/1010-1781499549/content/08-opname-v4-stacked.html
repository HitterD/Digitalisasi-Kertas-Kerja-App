Respons terhadap feedback kamu

  1. "Aset Tanpa Barcode" & "Aset Tidak Ada di Lokasi" — sekarang ditampilkan di bawah tabel utama sebagai section collapsible. Default: collapsed kalau ada data, expanded kalau ada. Header strip dengan ikon warning + counter item + tombol Tambah.
  2. Signature section — 3 kolom (Petugas 1, Petugas 2, PIC Ruangan) di bawah. Lebih kecil dari sebelumnya (90px tinggi).
  3. Sidebar dihapus — diganti 1-row context bar (56px) yang menggabungkan: room nav + progress ring 36px + dot grid horizontal scroll. Hemat ~280px horizontal.
  4. Tabel jadi lega — dengan sidebar hilang, tabel dapat full-width 1024-58=966px. Teks 12px cukup leluasa. Bandingkan dengan v3 yang tabel cuma ~750px.

Tablet vs Mobile — beda perlakuan

  • Tablet (≥768px landscape): pakai layout 1-row context + tabel. Sama dengan desktop karena lebar sudah cukup. Tombol ada di action bar (PDF, Sync, +Custom, Save/Load).
  • Mobile (<768px portrait): tabel jadi kartu vertikal per-aset. Tiap aset = card dengan: checkbox + barcode + nama (text lebih besar 12.5px) + toggle ADA/TDK + dropdown Kondisi + input Keterangan. Input selalu visible (tidak hover-only), lebih mudah disentuh.
  • Mobile navigation: 4-tab bottom bar (Aset, Tanpa BC, Salah, Ttd) menggantikan section collapsible. Tidak perlu scroll jauh untuk pindah section.
  • Mobile action bar: tombol-tombol tetap di atas konten (PDF, Sync, +Custom, Save/Load) — penting untuk workflow, tidak hilang di tab bar.

Prinsip responsif

  • Layout bukan "diperkecil dari desktop" — masing-masing viewport punya kompromi sendiri.
  • Mobile: informasi penting naik, scroll diminimalkan. Toggle ADA/TDK + scan barcode + checkbox = jejak 1-jari.
  • Tablet/desktop: densitas informasi tinggi, scroll vertikal untuk tabel, sidebar hilang.

Hover baris tabel (input fade in), klik row section (collapse), hover dot (tooltip), hover tombol (lift). Balas di terminal.
