Struktur halaman

  1. In-app header (sama): KKD + "Master Data & Recouncil" + sub-meta + BARCODE CHECKER
  2. Tab strip: 2 tab (Consolidation | Recouncil). Aktif = charcoal bg, non-aktif = ghost. Tab border-top menyatu dengan content card.
  3. Page header: meta uppercase + display title + 2 tombol (Tambah File + Lanjut Tahap 2)
  4. Summary 4-kolom: File Dimuat / Total Record / Duplikat / Unik Bersih (dengan status warna)
  5. Master table: Barcode + Nama + Dept + Lokasi + Sumber + Status. Status dengan pill: UNIK (hijau) / DUPLIKAT (merah).

Animasi

  • Tab hover: bg charcoal 4% transparan, active: charcoal 100% + oranye accent
  • Row matched: green tint, row missing: red tint (3px border kiri)
  • Status pill: dot pulse halus 2.4s
  • Card lift on hover
  • Tambah File: ghost button, Lanjut Tahap 2: terracotta primary
